# Windows final validation checklist

1. Build the signed x64 EXE and installer from the missing application project.
2. Record paths, byte sizes, and SHA-256 values.
3. Clean-install, upgrade, interrupt/recover, uninstall, and watchdog-recover on Windows.
4. Launch MONOLITH; verify local inference, image/file/screen input, and Windows OCR.
5. Record GPU backend/process telemetry and attach evidence.
